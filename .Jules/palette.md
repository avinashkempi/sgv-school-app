## 2025-01-31 - React Native hitSlop Shorthand\n**Learning:** In React Native, the `hitSlop` prop can accept a single number instead of an object like `{ top: 12, bottom: 12, left: 12, right: 12 }` to apply the value to all edges uniformly, which is less verbose.\n**Action:** Use a single number for `hitSlop` (e.g. `hitSlop={12}`) when applying a uniform touch target size.
