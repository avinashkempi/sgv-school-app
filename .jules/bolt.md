## 2024-05-24 - React Native Unvirtualized FlatList Anti-Pattern
**Learning:** Found a critical performance anti-pattern in `components/PostFeed.jsx` where a `FlatList` component was nested inside a parent `ScrollView` with `scrollEnabled={false}`. This completely disables virtualization, causing all items to render at once. Additionally, the list data (`posts`) was derived using an unmemoized `.flatMap()` on every render, which breaks referential equality and causes unnecessary deep re-renders.
**Action:** Replaced the unvirtualized `FlatList` with a standard `.map()` over the array, as the parent `ScrollView` is already handling the scrolling. Wrapped the data derivation (`.flatMap()`) in a `useMemo` hook to preserve referential equality and prevent unnecessary recalculations. Always avoid nesting `FlatList` with `scrollEnabled={false}` inside `ScrollView`, and always memoize derived data structures used in list rendering.
## 2024-05-24 - Expensive Computations in Render Anti-Pattern
**Learning:** Found components (e.g., `TeacherAttendanceTrendCard.jsx`) performing multiple array maps, filters, and reduces directly in the render function to derive complex KPIs without `useMemo`. This forces all these intensive calculations to re-run on every minor re-render or prop change, heavily impacting UI performance.
**Action:** Wrapped all the array-based KPI derivations into a single `useMemo` block that returns an object of the derived values, preserving referential equality for child components and ensuring recalculations only happen when the underlying data (`labels`, `data`) actually changes.
