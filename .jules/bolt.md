## 2026-10-20 - StyleSheet.create inside functional components
**Learning:** Found `StyleSheet.create` being called directly inside functional components like `HomeScreen` (`app/index.jsx`). This is a known React Native performance anti-pattern as it recalculates and recreates the style object on every single re-render, leading to unnecessary memory allocations and garbage collection overhead.
**Action:** Move `StyleSheet.create` calls outside of functional components to ensure they are only evaluated once when the file is loaded. Use `useMemo` if styles truly need to depend on dynamic theme variables.
\n## 2026-10-20 - FlatList nested inside ScrollView with scrollEnabled={false}
**Learning:** Found `FlatList` components with `scrollEnabled={false}` nested inside parent `ScrollView` components (e.g., in `components/PostFeed.jsx`). This is a critical performance anti-pattern. Setting `scrollEnabled={false}` on a `FlatList` forces it to render all items synchronously, completely defeating its virtualization benefits. In a large list of posts, this will cause severe performance degradation, memory spikes, and main thread blocking.
**Action:** Refactor layouts to use a single `FlatList` (or `SectionList`) for the entire scrollable area, using `ListHeaderComponent` and `ListFooterComponent` for surrounding content, rather than wrapping a `FlatList` in a `ScrollView`.
